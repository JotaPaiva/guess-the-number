# 🔢 Guess the Number

Welcome to **Guess the Number**, a simple yet addictive Python game where the computer picks a number between 1 and 100 — and it's your job to figure it out. But be warned: your guesses are limited, and the clock’s ticking!

> 🔍 *This project was developed as part of the course [100 Days of Code: The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/), taught by **Dr. Angela Yu***.

## 📦 Requirements
- Python 3.x  
- No external libraries required — just run and play!

## 🎮 How to Play
Run the game in your terminal. The system will randomly choose a number between 1 and 100. You'll be asked to select a difficulty level:

- **Easy mode**: 10 attempts  
- **Hard mode**: 5 attempts  

After each guess, you'll be told if the number is too high or too low. Try to guess correctly before you run out of attempts!

```bash
python main.py
```

## ✨ Features
- 🎲 Random number between 1 and 100  
- 🧠 Difficulty selection: easy (10 tries) or hard (5 tries)  
- 📉 Hints after each guess: too high or too low  
- 🏁 Win or lose message after the game ends  
- 🔄 Replayable for endless guessing fun
